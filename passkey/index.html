⁉️FAQs

Was ist ein Passkey und wofür brauche ich ihn?

Was: Ein Passkey ist ein digitaler Berechtigungsnachweis, der herkömmliche Passwörter bei Online-Anmeldungen ersetzt. Er ermöglicht den Login auf Webseiten oder in Apps ohne die Eingabe eines Passworts.

Warum: Mit einem Passkey entfällt eine Eingabe des Passworts, der Email-Adresse und wenn eingestellt auch eine Eingabe der Multifaktorauthentifizierung (mfa). Damit erfolgt eine schnellere und deutlich sicherere Anmeldung auch aufgrund der zu leicht gewählten Passwörter.


Wieso ist es sicherer bzw. Ist es sicher?

Ein Passkey ist sicherer als ein herkömmliches Passwort, weil er nicht auf den Servern von Webseiten gespeichert wird und dadurch vollständig immun gegen Phishing und Datenlecks ist.


Wie funktioniert ein Passkey?

Bei einem Passwort müssen Sie Ihren geheimen Code auf den Server der Webseite übertragen. Wird dieser Server gehackt, ist Ihr Passwort gestohlen. Ein Passkey nutzt ein kryptografisches Schlüsselpaar (öffentlicher und privater Schlüssel): Der Server speichert nur den öffentlichen Schlüssel (ein nutzloses Schloss), während Ihr privater Schlüssel niemals Ihr Gerät oder Ihren Passwortmanager verlässt.


Heißt -> Bequemer, einfacher, sicherer und leichter als ein Passwort.
